## probrem
Can you find the robots?
## 難しさ
簡単
## 解法
まずhtmlやcss,javaを確認。だが見つからず。
問題文にはrobotsというヒントを手掛かりに
ネットでweb　robotsと検索。
するとurlの最後につぎのurlを追加すると見れるらしい
```
/robots.txt
```
すると次のように表示される
```
User-agent: *
Disallow: /cc6b1.html
```
webのクローラーに対して禁止しているだけであって
暗号化などはされておらず閲覧可能である。
なので
```
/cc6b1.html
```
をurlに追加する。
するとフラグが出現。

## ここから学んだこと
まずwebのクローラー(bot)について。
ネットのhtmlの構造や情報を把握したり
aタグからほかのサイトとの関連性を創ったり
するために各サイトを巡回してデータベースに送ったり
するボットです。その時に把握されたくないファイル
などをrobots.txtに書くことにより
クローラーはそれを基本的に順守します。
またクローラーの代表的な役割としてはgoogleの検索結果に対する関連度順の表示などです。

ですが人間側に立つと暗号化も何もされていないので見れてしまう。
