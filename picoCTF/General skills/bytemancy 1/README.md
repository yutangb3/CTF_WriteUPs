## 解法
まずはpythonファイルを見てからインスタンスを立ち上げる。
すると以下の文言が出現。
```
⊹──────[ BYTEMANCY-1 ]──────⊹
☍⟐☉⟊☽☈⟁⧋⟡☍⟐☉⟊☽☈⟁⧋⟡☍⟐☉⟊☽☈⟁⧋⟡☍⟐

Send me ASCII DECIMAL 101 1751 times, side-by-side, no space.

☍⟐☉⟊☽☈⟁⧋⟡☍⟐☉⟊☽☈⟁⧋⟡☍⟐☉⟊☽☈⟁⧋⟡☍⟐
⊹─────────────⟡─────────────⊹
```
これはアスキーコードで10進数の101に対応する文字を1751回と書いてあるので
言い換えるとeを1751回繰り返したものを入力すればよい。
自分のlinuxで文字列を生成して貼り付ける。
```
python3 -c print("e"*1751 end="")
```
これを送るとflagが出現。

## ここから学んだこと
求められているのはコマンドではなく結果。
DECIMALは10進数。
ほかにはlinuxのみで実行する方法もある。
### 別解
これは%sが書式指定字と呼ばれるもので
この後に文字列が始まるという意味です。
また%**数字**sとすると数字分の文字を確保します。
今回はsの後に何も指定していないのでスペースが出力されます。
なのでスペースをeに変えるとeがずらりと並びます。
```
printf '%1751s' | tr ' ' 'e'
```
