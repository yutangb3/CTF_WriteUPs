## probrem
Unzip this archive and find the flag.

Download zip file
## 難しさ
簡単
## 解法
zipファイルを解凍すると
大量のディレクトリが出現。
そこでgrepコマンドを使って検索する。
-rで再帰的には配下のディレクトリも検索してくれる。
-iは大文字小文字を無視してくれる。
```
 grep -ri "picoCTF" ./
```
するとフラグが出現。
## 使用コマンド
### grepコマンド
```
grep [オプション]　"検索ワード" 対象ファイルやディレクトリ
```
## 答え
```
picoCTF{gr3p_15_m4g1c_ef8790dc}
```
## ここから学んだこと
grepでディレクトリに対して検索するときには
-rを用いる。
